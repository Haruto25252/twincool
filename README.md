# TWIN COOL Assistant

TWIN COOL は、8色×10枚（計80枚）のカードを使う一人用のカードゲームです。
このリポジトリには、プレイをサポートするブラウザ上のアシスタントツールが含まれています。

> **注意**: これは非公式のファンメイドツールです。MedalGameWorldのワールド作者様とは無関係です。

---

## ゲームルール

### カード構成

- **色**: 赤 / 青 / 緑 / 黄 / 灰 / シアン / 紫 / ピンク（8色）
- **数字**: 1〜10
- **合計**: 80枚（各色10枚）

### 基本ルール

1. **フリースペース（SP）** がフィールドに2つある。
2. 手番プレイヤーは手札から1枚を選び、フリースペースのいずれかに出す。
3. カードをスペースに出せる条件は以下のいずれか：
   - スペースが**空**である
   - スペースのカードと**同じ色**である
   - スペースのカードと**同じ数字**である
4. 手番終了後、山札からカードを補充する。
5. 出せるカードがない場合はゲーム終了。

### 目標枚数

| 目標 | 内容 |
|------|------|
| 13枚 | 元が返ってくるライン |
| 60枚 | トロフィー獲得ライン |
| 70枚 | 上位トロフィーライン |

## アシスタントツール

[ここ](https://Haruto25252.github.io/twincool/twin_cool_assistant.html) をブラウザで開いて使用できます。
スマホの Safari などで開き、「ホーム画面に追加」するとアプリのように使えます。

### 主な機能

#### アシスタント機能（実際のゲームを補佐）

| 機能 | 説明 |
|------|------|
| **カード残存表** | 山札に残っているカードを一覧表示。タップで除外／復活を切り替え |
| **グリッドロック** | 10枚以上除外後にロックして誤タップを防止 |
| **フリースペース設定** | 現在フィールドの2枚のカードを設定（除外済みカードも選択可） |
| **手札入力** | 手札（最大5枚）を入力。色・数字の複数同時選択に対応 |
| **提案** | 手札とSPの状態から最適な手を自動提案。タップで反映 |
| **モード切り替え** | 60枚 / 70枚 / 連鎖 の3モードで提案の戦略を変更 |

#### プレイモード（アプリ内でゲームをプレイ）

| 機能 | 説明 |
|------|------|
| **▶ プレイ** | プレイモード開始。ランダムで10枚除外 → 5枚手札配布 |
| **カード選択** | 手札カードをタップで選択（白リング表示）→ SPをタップで出す |
| **双方向選択** | SP先タップ → 手札タップ の順番でも出せる |
| **自動補充** | カードを出すたびに山札から1枚自動補充 |
| **出した枚数** | ヘッダーに表示。プレイ開始後に出した枚数をカウント |
| **💾 / 📂** | プレイ途中のセーブ / ロード |
| **↩ 最初からプレイ** | 出せるカードがなくなったとき（ゲームオーバー）に再スタート |
| **終了** | プレイ終了時に「開始時の状態に戻す」確認ダイアログを表示 |

#### シミュレーション

| 機能 | 説明 |
|------|------|
| **クリア確率シミュレーション** | 現在の状態から60/70枚クリアできる確率を試行回数 1k / 5k / 10k で計算 |
| **クリアルート検索** | 先行カード別にクリアできるルートを探索。「すべて表示」で手順を展開 |

### 操作手順（アシスタントとして使う場合）

1. 対戦相手がカードを除外するたびにカード残存表でタップして除外済みにする
2. フリースペースに置かれているカードを設定する
3. 手札に自分の現在の手札を入力する
4. 「提案」セクションに最適な手が表示されるので参考にする

### チュートリアル

画面上部の **?** ボタンをタップするとインタラクティブなチュートリアルが起動します（全10ステップ）。

| ステップ | 内容 |
|---------|------|
| ① | カード除外の操作 |
| ② | グリッドロックの使い方 |
| ③ | 手札入力の方法 |
| ④ | 提案カードの見方 |
| ⑤ | モード選択の説明 |
| ⑥ | プレイモードの紹介 |
| ⑦ | スタート時の10枚自動除外 |
| ⑧ | 手札の配布と自動補充 |
| ⑨ | カードの出し方（タップ操作） |
| ⑩ | ゲーム終了条件 |
