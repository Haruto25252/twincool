# TWIN COOL

TWIN COOL は、8色×10枚（計80枚）のカードを使う2人対戦カードゲームです。
このリポジトリには、プレイをサポートするブラウザ上のアシスタントツールが含まれています。

> **注意**: これは非公式のファンメイドツールです。MedalGameWorldのワールド作者様とは無関係です。

---

## ゲームルール

### カード構成

- **色**: 赤 / 青 / 緑 / 黄 / 灰 / シアン / 紫 / ピンク（8色）
- **数字**: 1〜10
- **合計**: 80枚（各色10枚）

### 基本ルール

1. **フリースペース（SP）** がフィールドに2つある。
2. 手番プレイヤーは手札から1枚を選び、フリースペースのいずれかに出す。
3. カードをスペースに出せる条件は以下のいずれか：
   - スペースが**空**である
   - スペースのカードと**同じ色**である
   - スペースのカードと**同じ数字**である
4. 手番終了後、山札からカードを補充する。
5. 出せるカードがない場合はパスとなる。

## アシスタントツールの使い方

`twin_cool_assistant.html` をブラウザで開くと使用できます。

### 機能一覧

| 機能 | 説明 |
|------|------|
| **カード残存表** | まだ山札に残っているカードを一覧表示。タップで除外/復活を切り替え |
| **フリースペース** | 現在フィールドにある2枚のカードを設定 |
| **手札入力** | 自分の手札（最大5枚）を入力 |
| **提案** | 手札とスペースの状態から、最適な手を自動提案 |

### 操作手順

1. 対戦相手がカードを除外するたびに「カード残存表」でタップして除外済みにする。
2. フリースペースに置かれているカードを「フリースペース」に設定する。
3. 「手札」に自分の現在の手札を入力する。
4. 「提案」セクションに最適な手が表示されるので参考にする。
5. リセットボタンで全状態をリセットできる。
